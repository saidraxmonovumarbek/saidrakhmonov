# saidrakhmonov

Personal website: home, projects, articles, milestones and experience.
Built with Next.js, Tailwind CSS and Motion.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Edit your content

You never need to touch the page code to update the site. Everything you
would want to change lives in the `content/` folder:

| What                                   | File                                   |
| -------------------------------------- | -------------------------------------- |
| Name, roles, bio, links, quote, nav    | `content/site.ts`                      |
| Projects                               | `content/projects.ts`                  |
| Tech stack chips                       | `content/tech.ts`                      |
| Milestones timeline                    | `content/milestones.ts`                |
| Work and education                     | `content/experience.ts`                |
| Highlights (kind words from others)    | `content/highlights.ts`                |
| Articles (one Markdown file each)      | `content/articles/*.md`                |

### Placeholders to replace first

The site ships with sample content. Before sharing the link, replace:

- [ ] `content/site.ts`: location, roles, about text, **LinkedIn / Telegram / Mail links** (they point to example addresses), the call-to-action email, and `url` (your real domain)
- [ ] `public/resume.pdf`: add your resume (the Resume tile links to it), or delete the Resume line in `content/site.ts`
- [ ] `public/avatar.jpg`: add a square photo and set `avatar: "/avatar.jpg"` in `content/site.ts`
- [ ] `content/projects.ts`: your real projects and links
- [ ] `content/highlights.ts`: real quotes, or set the list to `[]` to hide the section
- [ ] `content/milestones.ts`, `content/experience.ts`, `content/articles/`: your own story

### Write an article

Create `content/articles/my-title.md`:

```md
---
title: "My title"
summary: "One sentence about it."
date: 2026-11-10
tags: [Tag one, Tag two]
---

Your text in Markdown.
```

Add `draft: true` to keep it hidden while you are writing.

### Project screenshots

Each project card draws a gradient cover by default. To show a real
screenshot, put the image in `public/projects/` and set
`image: "/projects/my-app.png"` on that project.

## The animated banner

The pixel-art landscape on the home page is generated by code in
`lib/pixel-scene.ts` (no image files). It follows the theme: a daytime
scene in light mode and a moonlit one in dark mode. Change `SEED` in that
file for a different landscape, or edit the two palettes for new colours.

## GitHub Activity

The contribution graph reads the public calendar of the username set in
`content/site.ts`. For the most reliable results, add a `GITHUB_TOKEN`
environment variable (a classic token with no scopes is enough) and the
official GitHub API is used instead.

## Colours and fonts

Theme colours are CSS variables at the top of `app/globals.css`.
Fonts are set in `app/layout.tsx`.

## Deploy

Push the repository to GitHub and import it at https://vercel.com/new.
No configuration is needed.
