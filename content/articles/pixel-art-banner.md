The waterfall scene at the top of the home page looks like a GIF, but there is no image file behind it. The whole landscape is generated by code and painted onto a tiny `<canvas>`.

## A very small canvas

The scene is only **380 by 100 pixels**. The browser scales it up, and one CSS rule keeps the pixels sharp instead of blurry:

```css
canvas {
  image-rendering: pixelated;
}
```

## Mountains from noise

Each ridge is a line of heights produced by *value noise*: random numbers, smoothly blended. Stack a few layers at different scales and you get something that looks like a mountain range.

```ts
function fbm(x: number) {
  let sum = 0;
  let amp = 0.5;
  for (let octave = 0; octave < 4; octave++) {
    sum += noise(x) * amp;
    amp *= 0.5;
    x *= 2;
  }
  return sum;
}
```

Because the noise is *seeded*, the same landscape is drawn every time. Change the seed and you get a brand new world.

## Why it feels like a GIF

Three small tricks do most of the work:

1. **A low frame rate.** The scene updates about 12 times per second, just like classic pixel-art animation.
2. **A limited palette.** Gradients use ordered dithering instead of smooth blends.
3. **Layers.** The sky, the cliffs and the foreground trees are drawn once and cached. Only the moving parts (clouds, waterfalls, water reflections, birds) are redrawn each frame.

## Day and night

Switch the site theme and the scene swaps its palette: the sun rays and birds go away, and a moon, stars and fireflies come out.

The code lives in `lib/pixel-scene.ts` if you want to play with it.
